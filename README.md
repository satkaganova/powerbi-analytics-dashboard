# Interactive Power BI Business Analytics Dashboard

## 📌 Project Overview
This repository showcases an end-to-end Power BI analytics project designed to track business performance, operational KPIs, and regional trends through interactive dashboard visualization.

## 🛠️ Tools & Technologies Used
* **Business Intelligence:** Microsoft Power BI Desktop
* **Data Transformation:** Power Query (M Language) for ETL processing
* **Data Modeling & Calculations:** DAX (Data Analysis Expressions) for custom measures and calculated columns
* **Documentation & Output:** Executive PDF Report (`финал.pdf`)

## 📊 Key Dashboard Features & Insights
* **Sales & Profit Analysis:** Real-time tracking of revenue, profitability, and dynamic time-intelligence calculations.
* **Logistics & Regional Performance:** Geographical sales breakdown and delivery metrics.
* **Customer & Product Analytics:** Client segmentation and top-performing product categories.
* **Interactive Filtering:** Slicers, dynamic parameters, and cross-filtering for executive decision-making.

## 📁 Repository Files
* `финал.pdf` — Complete multi-page PDF export of the interactive Power BI report.
* `README.md` — Project documentation and overview.
